# storygen

Генератор коротких вертикальных видео из одной темы. Сценарий → озвучка → анимация → готовый MP4. Без камеры, без монтажа, без платных подписок.

Работает на Android (Termux) и на обычном Linux. Нужен только ffmpeg и Python.

## Что делает

```
тема → сюжет (5 сцен) → TTS (русский/англ) → анимация → MP4 1080x1920
```

Каждая сцена — это реплика диктора, надпись в кадре и тип движения: наезд камеры, выезд снизу или плавное проявление. Длительность сцены измеряется по реальной озвучке, поэтому картинка и голос не разъезжаются.

## Установка

```bash
# Linux (Debian/Ubuntu)
sudo apt install ffmpeg python3-pip fonts-dejavu
pip3 install edge-tts

# Android / Termux
pkg install ffmpeg python fontconfig ttf-dejavu
pip install edge-tts
```

## Использование

```bash
# Базовый запуск
python3 src/cli.py make "Как перестать откладывать дела" --out video.mp4

# Другой голос
python3 src/cli.py make "Секреты сна" --voice ru-RU-SvetlanaNeural

# Сценарий от нейросети (нужен OpenAI-совместимый API или Ollama)
export LLM_URL="http://localhost:11434/v1"
export LLM_MODEL="llama3.1"
export LLM_KEY="ollama"
python3 src/cli.py make "Что такое инфляция" --mode llm --out video.mp4
```

Режим `local` (по умолчанию) не требует интернета и ключей: сюжет строится по структуре короткого видео — крючок, напряжение, раскрытие, вывод, призыв.

## Структура

| Файл | Назначение |
|---|---|
| `story.py` | Генерация сюжета: локальные шаблоны или LLM |
| `tts.py` | Синтез речи с ретраями и обрезкой пауз |
| `script.py` | Модель сцены и сценария, тайминги |
| `render.py` | Рендер сцен и сборка финального ролика |
| `cli.py` | Командная строка |
| `run_all.py` | Пакетный прогон с кэшем озвучки |

## Как это устроено

**Озвучка.** edge-tts даёт нейросетевые голоса Microsoft бесплатно. Соединение идёт по WebSocket и на мобильном канале рвётся, поэтому каждая фраза синтезируется до 5 раз с растущей паузой. Аудио пишется потоком: метод `.save()` теряет данные на длинных репликах. После синтеза обрезается тишина по краям — иначе склейка сцен звучит рвано.

**Синхронизация.** Длина сцены не задаётся руками. Сначала синтезируется реплика, измеряется её длительность через ffprobe, и уже под неё рендерится видеофрагмент. Поэтому đuк всегда совпадает с концом фразы.

**Анимация.** `zoom` — наезд камеры через `zoompan`, `slide` — выезд текста снизу, `fade` — проявление по альфа-каналу. Все выражения опираются на время внутри сцены.

**Сборка.** Сцены склеиваются через concat, звук сводится с нормализацией громкости до -16 LUFS, результат — H.264 + AAC в MP4 с `faststart` для быстрого старта в браузере.

## Ограничения

- Нет музыкального сопровождения и звуковых эффектов.
- Нет видеопереходов между сценами — только смена плана.
- Текст в кадре — один заголовок на сцену, без построчной разбивки.
- edge-tts требует интернета: локального синтеза речи нет.
